How to host

  1. Push this repository to GitHub.
  2. In GitHub, open Settings > Pages.
  3. Set the source to Deploy from a branch, choose your main branch, and select the /docs folder.
  4. Wait for the site URL to appear, then open it and use the restore buttons.
